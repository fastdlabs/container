# FastD Container 文档

FastD Container 是一个简单高效的PHP依赖注入容器，实现了PSR-11标准接口，提供了灵活的服务注册和检索机制。

- [项目概述](overview.md) - 项目介绍、特性说明、架构设计
- [API 参考](api/) - 详细的API文档和使用指南  
- [安装与使用](installation.md) - 安装配置、快速入门、最佳实践

## 特性概览

- ✅ 实现PSR-11容器接口标准
- ✅ 支持多种服务类型（类、闭包、对象、数组等）
- ✅ 数组自动合并功能
- ✅ 单例模式支持
- ✅ 服务提供者注册机制
- ✅ ArrayAccess和Iterator接口实现
- ✅ 完整的单元测试覆盖
- ✅ PHP 8.2+ 支持
